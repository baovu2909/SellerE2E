Nhập từ Excel

Không chọn file → chỉ kiểm tra tải file mẫu và nút "Nhập dữ liệu" bị khoá khi chưa có file.

Chỉ nhập sản phẩm từ Excel

Chỉ chạy bước Nhập sản phẩm với file Excel đã chọn ở thẻ trên (tải file mẫu → chọn file → Nhập dữ liệu → kiểm tra tổng sản phẩm tăng hoặc lỗi hệ thống báo).
